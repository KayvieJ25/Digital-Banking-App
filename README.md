Project Description

The Digital Banking Client Card Integration System is a Java application designed to simulate the onboarding of banking clients and the integration of their debit/credit cards into a digital banking platform.

This system allows the bank to create clients, assign cards, and display card information securely.

This project was developed as part of a Java programming assignment.

Features

Create a banking client
Assign a card to a client
Display client card details
Secure card number masking
Simple console-based interface
Classes Included

Client.java
This class stores client information such as:

Client name
Client ID
Card information
Card.java
This class stores card information such as:

Card number
Balance
Card status
Includes secure card masking functionality.

OnboardingApp.java
This is the main class that:

Creates client objects
Creates card objects
Links client and card
Displays information
This is the entry point of the program.
